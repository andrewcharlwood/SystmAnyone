# Bundled terminology

`ctv3.csv.gz` (`code,term`): every current and optional NHS Clinical Terms
Version 3 (CTV3) concept with its preferred term, 269,509 rows. Redundant and
extinct concepts, and synonyms, are excluded.

Source: the CTV3 tables in the NHS England SNOMED CT UK Data Migration Workbench
(TRUD, release 43.0.0, September 2026). CTV3 content has been frozen since the
April 2020 release. No SNOMED CT content is included.
